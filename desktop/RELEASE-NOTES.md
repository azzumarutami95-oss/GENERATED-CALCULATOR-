Connection Design for Windows 10/11, 64-bit.

- Offline English interface for the embedded head plate calculator.
- Native project Save, Save As and Open dialogs; `.epd` file association.
- Desktop and Start menu shortcuts; per-user installation, no administrator account required.
- PDF reports and input JSON export.
- The calculation source is the same `embedded-beam.html` shipped in this repository. All model limitations remain applicable.

Download and run `Connection-Design-Setup-1.0.0-x64.exe`. Use `SHA256SUMS.txt` to verify the download.

This first release is not digitally signed. The release workflow tests the application, runs the installer silently on Windows, and checks the installed application before publishing.
